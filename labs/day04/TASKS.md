## 4장 실습: 모델 고르기

VS Code 터미널(`` Ctrl+` ``)에서 한 줄씩 실행한다. `<모델>`, `<리뷰>`만 바꾼다. 답을 한 번 하고 끝난다.

```
ollama run <모델> --verbose "다음 리뷰의 감성을 부정, 중립, 긍정 중 하나로만 답해. 리뷰: <리뷰>"
```

- 모델: `qwen3:4b-instruct-2507-q4_K_M`, `gemma3:4b`, `qwen2.5:7b-instruct` (`ollama list`로 설치 확인)
- 리뷰 A (2점): `녹아내렸어요 .. 구매한지 얼마 되지도 않았는데 녹아내렸어요ㅠㅠ`
- 리뷰 B (5점): `아주 마음에 들어요 디자인이 인덕션과 거의 같아서 깔끔하고 이쁩니다 ㅎㅎ`
- 리뷰 C (4점): `요리하고 나면 누렇게 변하고 냄새가 나는게 정상인가요??`

답 아래 `total duration`(전체 시간)과 `load duration`(모델 올리는 시간)을 표에 적는다. 모델 하나로 A·B·C를 끝내고 다음 모델로 간다.


C -> B -> A 순서로 실행함.

| 모델 | A 답 | B 답 | C 답 | A 시간 | B 시간 |
|---|---|---|---|---|---|
| qwen3:4b-instruct | 부정 | 긍정 | 부정 | 0.15초 | 0.21초 |
| gemma3:4b | 부정 | 긍정 | 부정 | 0.29초 | 0.18초 |
| qwen2.5:7b-instruct | 부정 | 긍정 | 부정 | 0.20초 | 0.25초 |


비교: ① 답이 다른 칸이 있나 ② 정답(A 부정, B 긍정)을 다 맞혔나 ③ 답이 같으면 빠르고 작은 모델

## 실행 전 예상

1. 세 모델 중 리뷰 3개를 가장 잘 맞히는 모델은? : 확정할 수 없음.
2. 리뷰 C는 4점이다. 모델은 뭐라고 답할까? : 부정
3. 같은 모델에서 첫 리뷰와 두 번째 리뷰의 응답 시간은 비슷할까? : 로드시간을 제외한다면 비슷할 것 같다.

<details><summary>정답</summary>

1. 차이 없다. 셋 다 A 부정, B 긍정, C 부정. 리뷰 3개로는 모델을 가를 수 없고, 6장에서 평점 라벨로 정확도를 재서 다시 비교한다.
2. 부정. 평점(4점)은 긍정 쪽인데 내용은 불만이다. F3이 잡아야 하는 "점수는 높은데 불만인 리뷰"다.
3. 아니다. 첫 번째는 모델을 메모리에 올리느라(load) 2~4.5초, 그다음은 0.2초 안팎이다. 모델이 클수록 load가 길다 (2.5 GB 2.3초 → 4.7 GB 4.5초).

</details>

**고른 모델:** `qwen3:4b-instruct-2507-q4_K_M` — 정답은 같고, 가장 작고 최신이다. 6장 정확도에서 다시 확인한다.

## 한 문장으로 답하기

**Base 모델에 "이 리뷰의 감성을 답해"라고 넣으면 왜 원하는 답이 안 나올 수 있을까?**

<details><summary>모범 답</summary>

Base 모델은 지시를 따르는 법이 아니라 "다음에 올 글"을 확률로 이어 쓰는 법만 배웠다. 그래서 답 대신 비슷한 질문을 더 이어 쓰거나 엉뚱한 글을 만들 수 있다. 지시를 따르게 추가 학습한 Instruct 모델(이름에 `instruct`, `it`)을 써야 한다.

</details>
