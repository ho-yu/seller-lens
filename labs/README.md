# labs

장마다 실습 폴더 하나: `labs/dayNN/` 안에 `TASKS.md`(할 일)와 실습 파일 하나. Day 번호는 장 번호와 같다 (1과목 Day05부터. 8장 = `labs/day08/`). Day02~03은 1장, Day04는 2~4장이다.

- 파일명: `<과목>_chNN_<주제>.py` (과목: `dl` 딥러닝 실전, `api` 데이터 수집 & API, `lc` LangChain, `rag` RAG). 예: `labs/day03/dl_ch01_loss.py`
- 실습에서 쓸 만한 코드는 `src/`로 옮긴다.
