# labs

Day별 실습 공간. 강의에서 배운 개념을 sellerlens 데이터로 다시 구현해 본다.

- 폴더: `labs/dayNN/`
- 파일명: `<과목>_chNN_<주제>.py` (과목: `dl` 딥러닝 실전, `api` 데이터 수집 & API, `lc` LangChain, `rag` RAG)
  - 예: `labs/day01/dl_ch01_loss.py`
- 과제 설명은 같은 폴더의 `TASKS.md`, 파일 구성과 이름 규칙은 [`docs/CONVENTIONS.md`](../docs/CONVENTIONS.md)를 따른다.
- 실습에서 쓸 만한 코드는 `src/`로 옮긴다. 옮긴 내용은 그날 일지의 "서비스에 반영한 것"에 적는다.
