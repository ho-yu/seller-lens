# 기능 진행 현황

> 서비스 기능이 어느 Day에 걸쳐 만들어졌는지 기록한다. 하루를 마무리할 때 그날 일지의 `기능`과 함께 갱신한다.
> 기능 정의는 [ROADMAP.md](ROADMAP.md), 계획 순서는 [CURRICULUM.md](CURRICULUM.md)를 따른다.
> 그날 시점의 코드는 git 태그 `dayNN`, 그날 바뀐 코드는 `git diff day<N-1> day<N> -- src/`로 본다.
