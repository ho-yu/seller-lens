|---|---|---|
| 손실(loss) | 예측이 정답에서 얼마나 틀렸는지를 숫자 하나로 낸 것이고, 학습은 이 숫자를 줄이는 방향으로 모델을 고친다 | `labs/day03/TASKS.md` |
| MSE | 숫자 예측(평점)에 쓰며, 차이를 제곱해 평균 내므로 오차가 2배면 loss는 4배다 (오차 1 → 2 → 4일 때 1 → 4 → 16) | `labs/day03/dl_ch01_loss.py` |

## 💬 질문

1. **Q. MSE에서 오차가 커지면 loss는 얼마나 커지는가?**
   - A. 차이를 제곱하므로 오차가 2배면 loss는 4배다. 오차 1 → 2 → 4일 때 loss는 1 → 4 → 16이다. 그래서 1점 틀린 리뷰 4개(loss 1씩)보다 4점 틀린 리뷰 1개(loss 16)를 더 나쁘게 본다.
2. **Q. 정답이 "부정"인데 부정일 확률을 낮게 말할수록 BCE는 어떻게 되는가?**
   - A. 천천히가 아니라 급격히 커진다. 0.99 → 0.9 → 0.5 → 0.1 → 0.01일 때 loss는 0.01 → 0.11 → 0.69 → 2.30 → 4.61이고, 확률이 0이면 무한대다. 확신하고 틀리면 크게 벌한다.
3. **Q. 두 모델이 모두 "부정"을 1등으로 맞혔다. loss도 같은가?**
   - A. 다르다. Cross Entropy는 정답 칸의 확률만 본다. 부정 확률 0.98인 확신 모델은 `-log(0.98)` = 0.02, 0.49인 애매 모델은 `-log(0.49)` = 0.71이다. 학습은 맞히는 것뿐 아니라 확신해서 맞히는 쪽으로 모델을 고친다.
4. **Q. LLM으로 리뷰를 분류할 때 loss를 직접 계산하지 않는데, 이 개념은 어디에 남는가?**
   - A. LLM은 이런 loss를 줄이도록 학습되어 다음 단어를 확률로 고른다. 그래서 확률이 낮은(애매한) 답은 믿기 어렵고, 실무에서는 분류 결과를 정답 라벨과 비교해 정확도로 평가한다 (1과목 6장). sellerlens에서는 애매한 리뷰를 "확신 낮음"으로 표시해 셀러가 직접 보게 한다.
